# MotoMap — landing page

Marketing site for **MotoMap**, an offline GPS tracker for motorcycle riders on Android. The page is
bilingual (French and English) and both languages are prerendered at build time.

Built with Next.js 16 (App Router, Turbopack, Cache Components), React 19, Tailwind CSS 4 and
TypeScript.

## Getting started

Requires Node.js 20.9 or later.

```bash
npm install
npm run dev
```

Open http://localhost:3000. You are redirected to `/fr` or `/en` (see [Languages](#languages)).

The repository's `.npmrc` points npm at the public registry, so installs work even if your machine
is configured for a private one.

## Configuration

| Variable | Required | Purpose |
| --- | --- | --- |
| `SITE_URL` | In production | Public origin, e.g. `https://motomap.app`. Used for canonical URLs, hreflang links, the sitemap, `robots.txt` and Open Graph. Falls back to `http://localhost:3000`. |

Site-wide constants (name, author, contact link and email, Google Play URL, theme colour, copyright
year) live in [`src/lib/site.ts`](src/lib/site.ts). Every download button points at `site.playUrl`.

## Languages

Visiting `/` (or any path without a locale) redirects to a localised URL. The locale is picked
from, in order:

1. the `NEXT_LOCALE` cookie, set when the visitor uses the language switcher;
2. the browser's `Accept-Language` header (q-values are respected);
3. French, the default.

### Editing copy

All text on the page is in [`src/i18n/dictionaries/`](src/i18n/dictionaries). `fr.ts` is the
reference: it defines the `Dictionary` type, and `en.ts` must have exactly the same shape. A missing
or misspelt key in `en.ts` is a type error, so run `npx tsc --noEmit` after changing copy.

### Adding a language

1. Add the code to `locales` and its tags to `localeTags` in
   [`src/i18n/config.ts`](src/i18n/config.ts).
2. Create `src/i18n/dictionaries/<code>.ts`, typed as `Dictionary`, and register it in
   `dictionaries/index.ts`.
3. That's it: the language switcher, sitemap, hreflang links and prerendering all read from
   `locales`.

## Adding or changing a section

Sections are components in [`src/components/Sections.tsx`](src/components/Sections.tsx). Each takes
its slice of the dictionary (`t: Dictionary["…"]`) as props. To add one: add its copy under a new
key in `fr.ts` and `en.ts`, write the component, then place it in `src/app/[lang]/page.tsx`.

The phone screens in `components/screens/` are hand-drawn SVG illustrations, not real map tiles or
screenshots.

## Colours

The palette is the app's default **Orange** theme, dark scheme (`Palettes.kt` in the app). The CSS
tokens in `globals.css` map onto its roles: `accent` is primary, `go` and `amber` are tertiary (GPS
lock, anything confirmed), `sky` is secondary (lean left), `stop` is error. The speed ramp in
`screens/geometry.ts` is the app's own and, as in the app, is deliberately not themed. The icons
reproduce the launcher icon, so they keep its `#0B0E14` background.

## Legal pages

`/[lang]/terms` and `/[lang]/privacy` publish the documents the app shows in Settings → Legal. Their
text is in `src/i18n/dictionaries/legal/`, taken from the app's `terms_*` and `privacy_*` strings.
When those change in the app, change them here too, and keep the edition and date in step. The
privacy page's URL is the one to give the Play Console.

## SEO

- Per-locale `<title>`, description, canonical URL and `hreflang` alternates (`layout.tsx`).
- Open Graph and Twitter cards with a generated image per locale (`opengraph-image.tsx`).
- JSON-LD for `MobileApplication` and `FAQPage` (`page.tsx`).
- `sitemap.xml`, `robots.txt` and a web manifest, all built from `SITE_URL`.

## Deployment

Any host that runs Next.js 16 works (Vercel, or `npm run build && npm start` on a Node server).
Set `SITE_URL` to the production origin before building, otherwise canonical and sitemap URLs point
at localhost.

### Vercel Web Analytics and Speed Insights

The root layout renders two Vercel components:

- `<Analytics />` (`@vercel/analytics`): page views, visitors, referrers, countries and devices.
  It uses no cookies, so no consent banner is needed for it.
- `<SpeedInsights />` (`@vercel/speed-insights`): real-user Core Web Vitals (LCP, INP, CLS, …).

To see the data, enable **Web Analytics** and **Speed Insights** in the project's dashboard on
Vercel; results appear after the next deployment. In development both run in debug mode and send
nothing (events are logged to the browser console). On other hosts the scripts load but have
nowhere to report.

## Content rules

The copy describes the Android app, whose source is in a separate repository. Its README is the
source of truth for features: don't advertise anything that isn't built yet (GPX export,
navigation, imperial units, auto-pause, `.mbtiles` import).

- MotoMap is a **paid, proprietary** app. Don't call it open source, and don't link development
  APKs for download.
- Any map imagery must keep its attribution: © OpenStreetMap contributors (ODbL), OpenTopoMap
  (CC-BY-SA), HikeBikeMap.
